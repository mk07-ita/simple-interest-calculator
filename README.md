# Simple Interest Calculator

## Description
This project is a Simple Interest Calculator that calculates the interest earned or paid on a principal amount.

## Formula
Simple Interest = (P * R * T) / 100

Where:
- P = Principal Amount (Initial amount)
- R = Rate of Interest (per year)
- T = Time (in years)

## How it Works
1. User enters Principal amount
2. User enters Rate of interest
3. User enters Time period in years
4. Calculator applies the formula: SI = (P*R*T)/100
5. Displays the Simple Interest and Total Amount (P + SI)

## Example
If P = 1000, R = 5%, T = 2 years
Simple Interest = (1000 * 5 * 2) / 100 = 100
Total Amount = 1000 + 100 = 1100
